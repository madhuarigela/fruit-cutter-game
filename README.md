# Fruit Cutter

A browser-playable, mobile-friendly fruit-slicing arcade game built with Phaser 3.

## Deploy for free with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish; the live URL appears in Settings → Pages.

## Controls
- Mouse or touch: swipe through fruit.
- Avoid bombs; bombs remove a life.
- Slice fruit quickly for combo multipliers.
- Personal best is stored in this browser's local storage.

## Current scope
Playable MVP: home screen, how-to-play, fruit spawning, swipe slicing, bombs, score, timer, lives, combos, game-over and restart. No ads appear in this version.

Authentication, cloud saves, advertisements, diamonds and purchases are not implemented yet.

## Dependencies
Phaser 3.90 is loaded from jsDelivr CDN, so the game needs an internet connection. This is a browser game, not yet a native Android package.

## Cost
The source code and Phaser are free. GitHub Pages may host a public static site at no charge under applicable account limits. Play Store distribution has separate requirements and a developer registration fee.
